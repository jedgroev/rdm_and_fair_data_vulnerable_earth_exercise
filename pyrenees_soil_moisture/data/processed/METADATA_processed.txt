FILES

soil_moisture_clean.csv
  Description : Quality-filtered soil moisture data. Outliers (>3 SD from
                site mean) removed. Missing sensor reads coded as NA.
                Site 3 data for 2024-07-12 to 2024-07-19 removed due to
                sensor malfunction (see README).
  Columns     :
    date        - Date of measurement (YYYY-MM-DD)
    site_id     - Site identifier (S1–S5)
    elevation_m - Elevation (m a.s.l.)
    moisture_mean_pct - Mean of 3 replicates (%)
    moisture_sd_pct   - Standard deviation of 3 replicates (%)
    n_replicates      - Number of valid replicates used (1–3)
    flag              - Quality flag: OK / OUTLIER_REMOVED / SENSOR_FAIL
  Rows        : 680

site_monthly_summary.csv
  Description : Monthly mean soil moisture per site, averaged across
                all valid measurement dates within that month.
  Columns     :
    site_id     - Site identifier (S1–S5)
    elevation_m - Elevation (m a.s.l.)
    month       - Month (1 = June, 2 = July, 3 = August)
    moisture_mean_pct - Monthly mean (%)
    moisture_sd_pct   - Standard deviation across dates (%)
    n_dates     - Number of measurement dates included
