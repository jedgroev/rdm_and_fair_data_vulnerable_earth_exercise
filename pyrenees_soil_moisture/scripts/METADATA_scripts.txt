METADATA - SCRIPTS
==================
Folder: scripts/
Last updated: 2025-08-06

Run scripts in the following order from the project root:

  01_data_cleaning.R  - Loads raw data, removes outliers, exports cleaned CSVs
  02_analysis.R       - Runs linear mixed model, exports model summary text
  03_figures.R        - Produces PNG figures from processed data

Requirements
------------
R version: >= 4.3
Packages  : tidyverse, lubridate, lme4, ggplot2

Install packages with:
  install.packages(c("tidyverse", "lubridate", "lme4"))
